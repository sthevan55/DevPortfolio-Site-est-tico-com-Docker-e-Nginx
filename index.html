POR TRÁS DOS BASTIDORES

Um site. Um container. Muitas possibilidades.

Este portfólio é um site estático servido pelo Nginx dentro de um container Docker. Assim, os arquivos são entregues pelo mesmo ambiente configurado na imagem.

✓Site HTML, CSS e JavaScript
✓Imagem oficial nginx:alpine
✓Mapeamento de portas 8081:80
Vamos conversar sobre tecnologia? ↗
terminal — docker⌘
$ docker build -t devportfolio .
# Constrói a imagem a partir do Dockerfile
$ docker run -d -p 8081:80 devportfolio
# Inicia o container em segundo plano
Abra no navegador: localhost:8081
